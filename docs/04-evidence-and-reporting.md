# 04. 증빙·평가·보고서

상태: 설계 기준 v0.1 · 2026-10-05.

## 지표 정의에 필요한 항목

이름, 적용 이유, 활동/산출/변화 구분, 단위, 측정 대상과 범위, 수식, 분자/분모, 중복 제거 기준, 측정 주기, 담당자, 원문 증빙, 기준선, 목표, 목표일, 증감 방향, 집계 방식, 표준 출처·버전, 확인 기준을 보관한다. 고급 항목은 접어 두되 의미를 생략하지 않는다.

외부 지표와 조직 자체 지표를 구분한다. IRIS+ 코드가 비슷하다는 이유로 자동 일치시키지 않는다. 예를 들어 PI4060은 중복을 제거한 고객 수이며 방문 횟수의 합계가 아니다. [공식 정의](https://iris.thegiin.org/metric/5.3/pi4060/)의 적용 조건·기간과 원문을 확인하고 담당자가 확정한다. 링크의 버전 표기와 본문 인용 버전이 다르면 그대로 기록하고 검토한다. SDGs 연결은 달성 인증이 아니며 SVI/SPC는 관련 자료 준비와 기준 매핑부터 지원한다.

## 예상 결과의 설계

AI는 사업계획에서 명시된 목표와 추정한 값을 구별한다. 예를 들어 주당 방문 가능 횟수 × 운영 주수 × 가동률로 예상 방문 수를 제안할 수 있다. 이 값으로 고유 이용자 수를 추정하려면 별도의 재방문 가정이 필요하다. 근거 없이 서로 바꾸지 않는다.

예상에는 입력 가정·출처·기준일·계산식·범위(보수/기준/확대)와 작성자·확인자를 저장한다. 목표 조정과 예상 수정은 별도다. 가정이 부족하면 질문하고, 답변 전에는 미정으로 둔다.

## 집계 규칙

| 종류 | 계산 | 금지할 방식 |
| --- | --- | --- |
| 활동 건수/금액 | 해당 기간의 유효한 사건 합계 | 같은 파일에서 중복 추출한 값을 재합산 |
| 고유 참여자 수 | 범위·기간 내 가명 키의 중복 제거 | 월별 고유 인원 단순 합계 |
| 비율 | 유효한 분자 합 / 대응 분모 합 | 월별 백분율 단순 평균 |
| 시점 값/누적 스냅샷 | 기준일까지 유효한 최신 확인값 | 누적값들을 다시 합산 |
| 변화량 | 비교 가능한 전/후 측정과 동일 대상 범위 | 서로 다른 표본의 차이를 개인 변화로 표시 |
| 정성 | 기준별 근거·관찰·사례·검토 의견 | 설명 없는 자동 총점 |

0과 미입력을 구분한다. 분모 0, 단위 불일치, 중복 기간, 정의 변경, 표본 누락을 경고한다. 목표가 없는 경우 달성률도 미설정이다. 낮아질수록 좋은 지표·유지 범위·마일스톤은 각기 다른 계산과 표현을 사용한다. 100% 이상 달성은 텍스트로 그대로 표시하되 막대만 시각적으로 제한할 수 있다.

이 시제품은 ‘높을수록 좋은 지표 + 프로젝트 시작일부터 기준일까지의 누적 스냅샷’만 지원한다. 최신 확인값을 선택하며 월별 합산은 하지 않는다. 비율·감소 목표·임의 시작일 집계는 운영 단계에서 별도 구현·검증한다.

## 원문에서 보고서까지의 추적

파일 버전 → 원문 위치(페이지/표/셀/타임코드) → 추출 후보 → 정리된 활동/관측값 → 계산 입력과 결과 → 검토 → 보고서 스냅샷.

AI 처리 결과에는 작업/모델/프롬프트 버전, 입력 출처, 제안 이유, 확인 상태를 남긴다. 점수 형태의 ‘신뢰도’는 검증된 보정 방법이 없으면 객관적 정확도로 표시하지 않는다. 사진만 보고 참여 인원을 확정하거나 활동이 있었다는 이유로 사회적 변화가 증명됐다고 판단하지 않는다.

## 정성 평가

계획 단계에 질문·대상·수집 시점·동의·판단 기준을 설계한다. 실제 인터뷰·관찰·만족도 응답을 원문과 함께 보관하고, 대표 사례뿐 아니라 반대 사례·변화 없음·불편과 개선도 기록한다. AI 요약에는 인용의 출처와 범위를 보여 준다. 민감정보·사진의 외부 보고서 사용은 수집 동의와 접근 범위에 맞춘다.

## 문서 형식 지원 계획

| 형식 | 원본 보관 | 내용 추출 목표 | 편집/출력 목표 |
| --- | --- | --- | --- |
| HWPX | 필수 | 문단·표·이미지·각주·구역 구조부터 실제 샘플 검증 | 대표 제출 양식으로 재현 검증, 원본과 생성본 모두 보존 |
| HWP | 필수 | 전용 변환기/추출 서비스의 호환성과 라이선스 검토 | 변환 또는 외부 편집 연계, HWPX와 동일 지원으로 표시하지 않음 |
| PDF/스캔 | 필수 | 텍스트/표/OCR·페이지 좌표 | PDF 출력, 원본 레이아웃의 완전한 역편집은 별도 범위 |
| DOCX/XLSX/PPTX | 필수 | 문단/시트·셀/슬라이드 구조 | 검증된 템플릿에 데이터·차트 삽입 |
| 사진/오디오 | 필수 | 촬영 메모/OCR/STT·타임코드 | 증빙 연결/회의록, 사진 자체로 성과 자동 확정 금지 |
| 기타 파일 | 정책에 따른 보관 | 지원 상태/대체 경로 안내 | 임의 변환 성공을 약속하지 않음 |

업로드 시 확장자·실제 형식·크기·압축/암호화·악성파일을 검사한다. 실패 이유와 대체 방법을 알리고 원본을 삭제하지 않는다. 첫 HWPX 검증 자료에는 실제 사업계획서와 병합 표·이미지·쪽 나눔이 있는 제출 양식을 포함한다. 사용자 원본은 허락 없이 외부 공급자에게 전송하지 않는다.

## 원하는 양식으로 출력

템플릿 업로드 → 항목/반복 표/이미지 영역 분석 → 내부 데이터와 연결 → 필수·조건부 항목 확인 → 테스트 출력·페이지 검수 → 템플릿 버전 확정. 새로운 양식마다 무검수 완전 자동 재현을 약속하지 않는다.

보고서에는 기간·목적·활동·예산·지표 목표/실적·정성 변화·차이 이유·한계·증빙 목록·검토/제출 이력이 포함된다. 사용자가 외부용/내부용 구성을 고르며 민감한 근거는 접근 권한에 따라 제외한다. 동일 데이터가 여러 제출 양식으로 이어지되 별도의 숫자를 손으로 관리하지 않는다.

## AI 도구 연결 규칙

회의 → 기록/결정/업무, 영수증 → 지출 초안, 현장 엑셀 → 관측 후보, 문서 비교 → 수정 제안, 변환/TTS → 원본을 참조한 새 파일. 도구의 결과는 실행한 프로젝트/자료 문맥에 저장하고 실패·비용·재실행을 관리한다. 산술 집계는 결정론적 코드로 처리하며 AI는 설명과 제안을 담당한다.
