# 15. 현장 자료에서 실적 제안·검토·보고까지

2026-10-06. 계획 문서의 지표 설계 다음 단계인 실행 결과 정리를 연결했다. 새로운 평가 도구를 따로 만드는 대신 기존 프로젝트의 자료·실적·보고 흐름을 확장했다.

## 사용 순서

1. 조직의 연간 목표와 프로젝트 지표를 정한다. 목표·예상은 실행 실적과 구분한다.
2. 프로젝트 **자료·기록**에 문서·사진·엑셀을 올리거나 현장 기록을 작성한다. 원본 버전은 그대로 유지한다.
3. **성과 → 자료에서 실적 찾기**에서 파일 버전과 확인할 지표(최대 8개)를 선택한다.
4. AI가 이미 실행된 결과 후보와 인용·위치·집계 날짜·불확실한 점을 제안한다. 자료에 목표나 예상만 있으면 실적으로 취급하지 않는다. 모르는 수치·날짜는 비워 둔다.
5. 담당자가 원본을 보고 값·단위·기간·중복 여부를 확인하고 수정한 뒤 **검토 전 기록**으로 저장한다. 수치가 없을 때 0으로 채우지 않는다.
6. 관리자가 원본과 제안을 확인하거나 보완을 요청한다. 확인 전 기록은 대시보드·연간 집계·보고서에서 제외한다.
7. 프로젝트/연간 보고서에는 확인된 값과 원본 버전, 최초 AI 제안, 담당자 설명·검토 시각을 함께 남긴다. DOCX·XLSX·HTML 출력에도 포함한다. 생성된 보고서는 이후 변경으로 덮어쓰지 않는다.

## 원본과 지원 범위

- HWPX·DOCX·XLSX·TXT·MD·CSV·TSV·JSON·LOG: 서버가 비공개 저장소의 원본 또는 저장된 현장 기록을 읽는다. 브라우저가 보낸 텍스트를 원본으로 신뢰하지 않는다.
- JPG·JPEG·PNG·WEBP·PDF: 보관된 파일 전체를 OpenAI에 전달한다. 이 경우 인용문·페이지 표시는 AI가 읽은 내용으로, 텍스트 파서의 대조 결과와 구분하여 안내한다. 원본 미리보기·다운로드가 가능하다.
- 자료 이름과 파일 시그니처를 확인한다. 외부 URL이나 모델이 제시한 URL을 다운로드하지 않는다.
- 파일당 8MB, PDF 5MB. 텍스트는 3만 자·200개 문단/행까지. 초과한 자료는 앞부분만 조용히 분석하지 않고 분할 업로드를 안내한다. 원본 보관 한도 25MB와 AI 분석 한도는 다르다.
- HWPX/DOCX의 본문·표 텍스트, XLSX의 저장값만 읽는다. 수식 실행·변경 사항 전체·사진 속 사람 수 추정·개인 속성 추정은 하지 않는다. 암호 문서·손상 파일은 거절한다.
- 음성/STT, 구형 HWP·XLS의 직접 분석, 다수 파일 통합 분석은 아직 지원하지 않는다. 데모의 AI 분석을 실제 호출처럼 표시하지 않는다. 로그인한 조직에서 실제 기능을 사용한다.

## 권한·검토 이력

- 조직 소속, 프로젝트 배정, 쓰기 권한, 진행 중인 상태를 확인한다. 읽기 전용 구성원·다른 조직은 분석할 수 없다. 유료 호출 후에도 권한과 지표 버전을 다시 검사한다.
- 분석은 실적을 저장하지 않는다. `measurement.add`만 검토 전 기록을 만들며, 관리자 확인은 기존 권한 규칙을 그대로 적용한다.
- 서버가 제안에 24시간 유효 HMAC 서명을 붙인다. 조직·사용자·프로젝트·지표 버전·파일 버전에 묶이며, 클라이언트는 최초 AI 인용이나 제안값을 조작할 수 없다. 검토한 최종 수치는 수정 가능하다.
- 서명키는 기존 서버 AI 키와 목적 구분 문자열로 구성한다. 키가 교체되면 저장 전 초안은 다시 분석해야 한다. 이미 저장한 검토 이력은 유지한다. 별도 환경변수는 추가하지 않는다.
- 동일 제안을 중복 저장하지 않는다. 같은 날짜/겹치는 기간의 중복 **확정**은 기존 도메인 규칙으로 차단한다. 별도 파일에 같은 사람이 있는지 의미상 중복 제거까지 자동으로 보장하지는 않는다.
- 실적 분석은 조직당 이동 24시간에 20회. 기존 계획 분석 한도와 별도다. 직렬화 트랜잭션에서 유료 호출 전 예약하며 실패한 호출도 포함한다.
- `store:false`, 외부 도구 없음, JSON Schema 응답, 45초 AI 응답 제한. 민감한 원본이나 공급자 오류 전문을 로그로 출력하지 않는다. 전송 범위는 실행 버튼 옆에 설명한다.
- 별도 DB 테이블/마이그레이션은 없다. 기존 조직 상태의 실적에 검토 근거 필드를 추가하고, 기존 operations에 호출 이력을 남긴다. 조직 JSON 저장 한도 1MiB는 그대로이며 정규화는 후속 과제다.

## 검증

- 전체 자동 테스트 **107/107**, 타입 검사 통과. 원본 추출·인용 대조·알 수 없는 값·날짜/비율 검증·서명 위변조/만료/타인 사용·권한 회수·호출 한도·중복 기록·확정 전 집계 제외·프로젝트/연간 보고 스냅샷·Word/Excel/HTML 근거 보존 포함.
- 브라우저: 실제 React UI·서버 핸들러·PostgreSQL 테스트 DB, AI 응답만 가상으로 사용. 제안 15명을 14명으로 수정 → 검토 전 저장 → 원본 확인 → 관리자 확정 → 보고서 14명 및 최초 제안 15명 보존. 화면 오류 없음, 모바일 390px 가로 넘침 없음.
- 실제 OpenAI: 기존 `gpt-6-luna` 설정으로 개인정보 없는 합성 XLSX·PNG·PDF 각각 1건 분석. 세 형식 모두 실제 인원 15명, 기준일 2026-09-30 추출 확인. 개별 분석 약 4~6초. 복잡한 실제 자료의 정확도·소요 시간을 보장하는 수치는 아니다.
- 실제 운영 조직 자료에 대한 관리자 검수/최종 제출 인수는 별도다. 이 기능은 공식 평가 인증이나 자동 평가 점수를 만들지 않는다.
