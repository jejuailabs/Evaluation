## B. 첫 운영 출시까지의 순서

### B1. 계정·조직·저장·권한

관계형 DB와 객체 저장소, 인증 방식, 배포 환경을 선정한다. 조직/프로젝트 권한과 명령 API, 버전 충돌, 감사기록, 파일 검증·비공개 접근, 백업 복구를 먼저 구현한다. 스키마 마이그레이션과 데이터 이전 경로를 버전 관리한다.

완료: 다른 조직의 ID를 요청에 넣어도 조회·수정·다운로드·AI 검색이 불가능하다. 초대 철회·역할 변경·퇴사 후 권한을 검증한다. 장애 복구 연습에서 원본과 참조가 유지된다. 두 사람이 같은 버전을 수정하면 덮어쓰지 않고 충돌을 해결한다.

### B2. 운영 기능

업무 하위 항목·의존성·반복·일정·댓글·멘션·결정, 담당자 변경과 인수인계, 목록/보드/캘린더, 문서 검색·검토·복원, 예산 항목·재원·지출 승인·지급·증빙을 구현한다.

완료: 실제 프로젝트의 계획 변경·담당자 부재·반려·지출 취소·부분 지급을 처리할 수 있다. 업무는 평가 설정 없이 진행된다. 집행과 지급, 약정 전환을 중복 합산하지 않는다.

### B3. AI 보조와 성과

작업 큐, 원문 위치가 있는 추출, 계획/활동/목표 후보, 사람의 검토, 버전별 지표 정의, 정량/정성 수집, 중복 제거·기간 집계, 목표와 예상의 별도 버전을 구현한다. 원문 변경 후 영향 범위를 표시한다.

완료: 실적 값에서 원문 버전까지 추적 가능하다. 예상 수치를 확인 실적으로 처리하지 않는다. AI가 실패해도 업무·수동 입력·보고가 가능하다. 대표 사업에서 IRIS+ 적용 여부를 설명하고 자체 지표와 구분한다.

### B4. 보고·파일럿

실제 HWPX 포함 대표 출력 양식, 표/차트/사진 배치, 필수 항목, 내부/외부용 범위, 검토·확정·제출·정정을 구현한다. 조직 담당자와 실제 사업 하나를 끝까지 운영한다.

완료: 집계와 출력 수치가 같고 보고서에서 근거를 찾을 수 있다. 제출 후 원본을 변경해도 제출본은 변하지 않는다. 템플릿의 병합 표·쪽 나눔·사진·각주를 실제 출력물로 검수한다. 기간·담당자·권한 변경을 포함한 최종 인수 테스트를 통과한다.

## C. 확장 순서

회의/STT·TTS·파일 변환 → 외부 자료 수집·모바일/오프라인 → 복수 재원과 인건비 배분·수익/입금 → 조직 포트폴리오·가용 인력 → 장기 성과/코호트 → 외부 회계·일정·드라이브 연동.

기능 추가마다 기존 프로젝트·문서·증빙·권한을 사용한다. 기능별 별도 자료함·별도 사용자·별도 수치 사본을 만들지 않는다.

## 대표 인수 시나리오

| 시나리오 | 기대 결과 |
| --- | --- |
| 평가를 설정하지 않은 프로젝트 생성 | 업무·자료·예산 사용 가능, 성과는 미설정 |
| 0 입력 / 미입력 / 미확정 값 | 서로 구분, 미확정 값은 확인실적에서 제외 |
| 8월 누적 60명 + 9월 누적 86명 | 9월 누적 86명, 146명으로 합산하지 않음 |
| 같은 사람의 여러 방문 | 방문 횟수와 고유 인원 분리 |
| 예산 100, 확정 30, 약정잔액 20 | 사용 가능 50, 지급 여부로 집행액 중복 증가 금지 |
| 다른 프로젝트/조직의 증빙 연결 | 서버에서 거부 |
| 파일 v1 근거로 보고 후 v2 등록 | 제출본은 v1 유지, 재검토 알림 |
| 승인 후 목표·정의 변경 | 새 버전과 이유, 기존 비교 기준 보존 |
| 작업 재시도·더블 클릭·동시 수정 | 중복 데이터/중복 지급 방지, 충돌 표시 |
| 파일 추출 실패·저장 실패 | 원본·입력 유지, 실패 이유와 재시도 |
| 보고서 출력에 사용자 HTML 포함 | 코드 실행 없이 문자로 표시 |
| 기한이 다른 월에 있음 | 캘린더 이동으로 확인, 목록과 동일한 데이터 |

## 이번 단계 검증

`npm test`: 계산·범위·증빙·스냅샷 관련 회귀 테스트.

`npm run build`: 타입 검사 및 배포용 프런트엔드 빌드.

브라우저: 데스크톱/모바일 화면, 메뉴·프로젝트·업무·성과·보고 흐름, 테마, 파일 저장/버전, 새로고침 후 상태를 확인한다. 실제 운영 권한과 HWPX 의미 추출은 이번 검증에 포함되지 않는다.

첫 파일럿 조직과 대표 서식, AI 모델과 비용 한도, HWP/HWPX 변환·편집 공급자와 라이선스, 조직별 승인 정책. UI 뼈대는 진행하되 이 결정이 필요한 운영 기능에 대해 완료를 주장하지 않는다.
