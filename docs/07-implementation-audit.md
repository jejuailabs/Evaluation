# 07. 프로젝트 운영 기능 재점검

**후속 구현: 2026-10-06 연간 계획·업무 수정/보드/통합 일정·현장 기록·기준 라이브러리·기간 집계·정성·정정·연간 보고를 추가했다. 아래는 10월 5일 당시 감사 기록이며, 최신 구현 판정은 [09 문서](09-annual-lifecycle.md)를 함께 적용한다.**

점검일: 2026-10-05. 기준: 사용자 대화 전체, 제품 문서 01~06, 실제 화면 컴포넌트, 서버 명령·권한·집계 코드와 회귀 테스트.

**판정: 프로젝트 운영 SaaS의 기초 흐름을 구현한 상태이며, 모든 운영 기능이 구현된 상태가 아니다.** 화면에 탭이 있거나 예시 데이터가 보인다는 이유로 완료 처리하지 않는다. 아래 ‘구현’도 기재한 범위만 뜻하며 운영 환경 인수 완료를 뜻하지 않는다.

## 현재 인프라와 인증

- 현재 공개 서비스의 업무 DB: Cloudflare D1. 파일 원본: 비공개 R2. Supabase DB로 이전된 상태가 아니다.
- 기존 공개 인증: ChatGPT 로그인. 사용자는 Google 로그인을 요구했다. Google 전환의 실제 활성화와 검증 상태는 08 문서에 별도 기록한다.
- Supabase MCP 접근은 확인했다. `vibe` 조직은 무료 요금제이며, `projecthub`가 활성 상태다. `novel`, `funjeju's Project`는 비활성 상태다.
- 새 전용 프로젝트와 기존 프로젝트 중 연결 대상은 사용자 확인이 필요하다. 인증 연결과 업무 DB 이전은 별개 작업이다. 인증만 Supabase로 연결한 상태를 DB 이전 완료로 표시하지 않는다.

## 특히 수정해야 하는 해석

1. **‘파일을 받는다’와 ‘내용을 이해한다’는 다르다.** 현재 HWPX와 음성도 원본 보관까지만 가능하다.
2. **예상값은 사용자가 적는 값이다.** AI가 사업계획으로 수치를 예측하거나 근거를 검증하지 않는다.
3. **IRIS+는 데모 참고 예시다.** 실제 새 조직에서는 자체 지표만 추가할 수 있다.
4. **기간 보고는 현재 누적 기준일 방식이다.** 8월 누적 60, 9월 누적 86을 146으로 더하지 않는 것은 구현했지만, 임의 기간의 고유 인원이나 월별 신규 인원 집계는 아니다.
5. **과거 시점의 예산·업무 상태를 복원하지 않는다.** 보고서 생성 시 해당 날짜 범위의 항목에 현재 상태를 적용한다. 나중에 만든 8월 보고서를 ‘8월 당시 상태’로 간주하면 안 된다.
6. **권한 테스트 통과와 실제 조직 인수는 다르다.** Google 계정 두 개, 실제 파일, 초대 수락·철회·권한 회수까지 운영 환경에서 추가 확인해야 한다.

## 다음 구현 순서와 완료 기준

### 1. 인증과 저장 기반

Google → Supabase Auth → 조직 소속 확인. Supabase 연결 대상 확정, OAuth 설정, 기존 사용자 ID와 자료 이전 방침 결정. DB 이전을 선택하면 PostgreSQL 스키마·RLS·Storage 정책·트랜잭션 API·데이터 대조·복구 경로까지 함께 구현한다.

완료 기준: 다른 조직 자료가 차단되고, Google 계정 두 개로 조직 생성/초대/업무/파일 저장·다운로드/로그아웃/재로그인까지 통과한다.

### 2. 프로젝트 일상 운영

프로젝트 수정·종료·보관, 업무 수정·담당자 변경·하위 업무·보드, 댓글·알림, 통합 일정, 활동 기록과 다중 첨부, 미분류 자료함·검색·버전 복원. 실제 담당자가 바뀌거나 일정이 변경되어도 새 프로젝트를 만들 필요가 없어야 한다.

### 3. 예산과 정산

예산 항목·재원·담당자 배정, 신청→검토→승인/반려→부분/전체 지급, 취소·정정, 증빙 누락, 상태 전이 이력, 조직 통합 대시보드. 회계 정책과 자가 승인 허용 여부는 조직별 설정으로 관리한다.

### 4. 평가 설계와 현장 기록 연결

계획서 추출→KPI 후보와 예상 근거→사람의 확정, 검증된 기준 라이브러리, 정량·정성 입력, 현장 증빙 자동 제안, 기간/집계 방식/중복 기준, 목표·실적 정정 이력. AI 실패 시 수동 운영이 가능해야 한다.

### 5. 원하는 양식으로 보고

기간·대상·지표별 집계와 차트, 원문 추적, 실제 조직의 대표 HWPX/DOCX/PDF 양식, 검토·제출·정정본 고정. AI 사무 도구는 프로젝트와 자료함을 공통으로 사용하도록 순차 연결한다.

## 검증 한계

이번 재점검은 요구사항과 실제 코드/테스트 대조다. 자동 테스트는 구현한 기능의 회귀 확인이며 미구현 기능을 대신 검증하지 않는다. 모든 운영 기능이 완성되었다거나 출시 가능하다는 판정은 하지 않는다.
