# 02. 사용 흐름과 화면

상태: 설계 기준 v0.1 · 2026-10-05.

## 탐색 구조

전역: 조직 전환 / 통합 검색 / 알림 / 빠른 기록 / 내 계정. 주 메뉴는 홈·프로젝트·자료함·보고서 네 개다. 조직과 멤버·청구·보안 설정은 조직 메뉴 아래에 둔다.

| 화면 | 먼저 보여 줄 것 | 주요 행동 |
| --- | --- | --- |
| 홈 | 내 할 일, 지연/확인 요청, 프로젝트별 일정·예산·성과 | 업무 처리, 기록 등록, 프로젝트 이동 |
| 프로젝트 목록 | 담당자·기간·상태, 예산과 성과의 별도 상태 | 만들기, 검색/필터, 보관 |
| 프로젝트 요약 | 목적·담당·기간·다음 마감, 운영과 목표 현황 | 상태 확인 후 관련 탭으로 이동 |
| 업무 | 목록/보드/캘린더, 담당·마감·상태 | 추가, 분담, 완료, 변경 사유 |
| 자료·기록 | 원본, 현장 기록, 회의, 버전·검토 상태 | 드롭/모바일 등록, 연결, 비교 |
| 예산 | 배정·약정잔액·확정집행·지급·사용가능액 | 신청·검토·지급, 증빙 연결 |
| 성과 | 목표·예상·실적·측정 기간·증빙 상태 | 지표 정의, 기록, 검토, 이유 설명 |
| 보고서 | 제출 기간·양식·준비 상태·제출본 | 누락 해소, 생성, 검토, 확정 |

초기에는 모든 기능의 설정을 노출하지 않는다. 프로젝트 내 탭에서는 선택된 프로젝트·기간·필터를 유지하고 뒤로 가기로 복원한다.

## 주요 흐름

### 프로젝트 시작

1. 이름·목적·기간만으로 생성하고 바로 업무를 등록한다.
2. 사업계획서·소개서·예산서를 추가하거나 자유롭게 작성한다.
3. AI 분석 작업은 백그라운드에서 처리한다. 처리 중에도 업무 화면을 쓸 수 있다.
4. 추출된 활동·대상·일정·예산·예상 변화를 원문과 함께 검토한다.
5. 필요한 지표·수집방법·담당·주기를 고르고 목표/예상을 구분하여 확정한다.
6. 선택한 수집 주기에 따라 기록 요청과 일정이 생성된다.

### 일상 운영

홈에서 업무를 확인 → 업무 상세에서 댓글·회의·자료·지출을 연결 → 현장에서는 사진·녹음·파일·짧은 메모로 기록 → 시스템이 이미 아는 날짜·프로젝트·담당자는 채움 → 확인이 필요한 항목만 질문.

한 번의 활동에 여러 파일이 붙을 수 있고, 같은 증빙을 예산과 성과에 참조할 수 있다. 파일을 복사하여 서로 다른 원본을 만들지 않는다. 참여자 개인정보는 필요한 권한의 별도 영역에 보관한다.

### 종료와 보고

프로젝트·기간·양식을 선택 → 누락 증빙/미확정 수치/기간 불일치 확인 → 목표 대비 차이와 정성적 변화 설명 → 표·차트·문서 미리보기 → 담당 검토 → 확정된 스냅샷과 제출 이력 저장.

확정 후 원본이 바뀌어도 제출본을 자동 갱신하지 않는다. 관련 변경을 알리고 새 보고서 버전으로 정정한다.

## 역할별 홈

- 담당자: 오늘/이번 주 업무, 내가 올린 자료 중 확인 요청, 내 지출.
- 프로젝트 책임자: 지연·업무 편중, 예산/목표 추세, 누락/검토 요청.
- 조직 관리자: 프로젝트별 진행, 담당자별 업무량, 재원과 집행, 성과와 위험.
- 회계/평가 담당자: 본인의 승인·검토 대기열. 권한 범위 내 자료만 보여 준다.

권한이 없는 항목은 검색 결과·자동완성·알림·차트·AI 답변에서도 노출하지 않는다.

## UX의 구체적 기준

- 데스크톱 본문 16px 이상, 주요 설명 17–18px. 모바일 본문 16px 이상, 조작 영역 44px 이상.
- 표는 가독성을 위해 수평 스크롤 또는 카드로 전환. 중요한 수치의 단위와 기간을 생략하지 않는다.
- 버튼 이름은 ‘저장’, ‘기록 추가’, ‘확인’, ‘보고서 만들기’처럼 행동을 표현한다.
- 목표 미설정/미입력/0/확인 필요/확인됨/집계 제외를 구분한다.
- 저장 중·저장 실패·업로드 중·추출 실패·재시도를 명확히 표시한다. 실패 시 입력을 지우지 않는다.
- 키보드 탐색·초점·모달 닫기·스크린리더 이름, 대비와 축소 동작을 확인한다.
- 예측에는 기준일과 근거, 차트에는 텍스트 요약/표를 제공한다.
- 메뉴와 완료율을 늘리지 않는다. 업무 진행률·예산 집행률·성과 달성률을 한 점수로 합치지 않는다.

## 조직 자료를 중앙으로 모으는 방식

사용자에게는 게시판처럼 편한 ‘기록 남기기’를 제공한다. 짧은 글, 여러 파일, 사진, 음성, 엑셀을 하나의 기록에 함께 담는다. 기록은 프로젝트 활동 피드에 나타나고 첨부 원본은 조직 자료함에서 중복 없이 찾아진다. 현재 시제품의 파일별 등록은 이 수집 화면을 위한 최소 단계이며, 다중 첨부 활동 기록과 미분류함은 다음 단계에서 구현한다.

1. 프로젝트 화면에서 올리면 프로젝트·작성자·등록 시각을 자동 지정한다. 실제 활동일은 별도로 입력/수정 가능하다.
2. 조직 공통 입구에서는 프로젝트 미지정 등록을 허용한다. 미분류함에서 시스템 추천을 보고 담당자가 분류한다. 미분류 자료를 조직 전체에 자동 공개하지 않는다.
3. 파일을 첨부하고 자유롭게 설명한다. 회의/현장 활동/지출/참고자료는 분류 제안이며 필수 긴 양식을 강요하지 않는다.
4. 원본 저장 성공과 추출 진행을 분리한다. 처리 완료를 기다리지 않고 업무를 계속한다.
5. 녹음→회의록·결정·업무 후보, 엑셀→표·실적 후보, 사진→현장 증빙, 글→활동 기록으로 이어진다. 근거와 일치하는지 확인하기 전에는 확정 실적에 반영하지 않는다.
6. 각 기록은 업무·지표·집행에 참조로 연결한다. 각각에 파일을 복사하지 않는다.

자료함은 파일 중심 보기, 활동 피드는 기록 중심 보기, 성과/예산은 연결된 근거 중심 보기다. 세 화면은 같은 자료를 서로 다른 목적에 맞게 보여 준다. Google Drive처럼 탐색·미리보기·검색·버전 기능을 먼저 갖추고, 표/문서/슬라이드의 완전한 공동 편집기는 별도 범위로 확장한다.

받는 사람의 권한, 수정 제안/검토/확정, 원본 사용 범위를 기록에 붙인다. 마감이 있는 자료 요청은 담당자·기한·제출 항목을 가진 업무로 생성하여 수집 누락을 줄인다.

## 첫 시제품의 화면 범위

홈, 프로젝트 목록/생성, 프로젝트 6개 탭, 자료함, 보고서 목록을 구현한다. 업무 상태 변경·파일 버전·예산 기록·실적 확인·보고서 스냅샷을 실제로 연결한다. 캘린더는 월별 마감일 조회다. 조직 초대·검색 고도화·알림·AI 분석·정식 결재·업무 의존 관계는 시제품 완료로 간주하지 않는다.
