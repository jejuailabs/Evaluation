## 브라우저에서 확인한 동작

- 프로젝트 생성: 이름·목적·예산으로 생성, 평가 지표 없이 요약 화면 진입.

- 파일: 직접 만든 무개인정보 TXT 예시를 등록, 새로고침 후 자료 목록에 유지.

## 검증 한계

- 브라우저 자동화의 다운로드 완료 이벤트가 시간 초과되어 최종 다운로드 파일 수신은 확인하지 못했다. HTML 생성 함수의 출력과 이스케이프는 자동 테스트로 확인했다.
- 파일 선택 자동화가 지연되었으나 최종 등록·재로딩 후 목록 유지는 확인했다. 버전 추가와 원본 재다운로드의 전체 UI 흐름은 추가 확인이 필요하다. 원본 버전 참조 보존은 자동 테스트로 검증했다.
- 모바일 최종 스크린샷 캡처가 도구 오류로 완료되지 않았다. 초기 모바일 화면을 시각 확인했고 수정 후 DOM 폭만 확인했다. 반응형 최종 시각 검수는 후속 과제다.
- 서버 권한, 실제 협업, HWPX 추출/편집, AI 처리, 정식 제출·승인은 이번 구현과 검증 대상이 아니다.

`screenshots/home-desktop.png`는 이번 로컬 기본 화면의 캡처다. 검증을 위해 추가한 예시 프로젝트/업로드/보고서는 검증 브라우저에만 남으며 초기 배포 데이터에는 포함되지 않는다.
