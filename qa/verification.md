2026-10-05 · 로컬 시제품 · 실제 조직 데이터 미사용.

## 자동 검증

- `npm test`: 26개 통과, 실패 0개. 누적 집계, 미확정 제외, 0과 결측, 교차 조직/프로젝트 참조 거부, 집행/지급 중복 방지, 증빙 사후 연결, 보고서 불변성, HTML 이스케이프 등.
- `npm run build`: TypeScript 검사 및 Vite 배포 빌드 성공.
- Windows 제한 환경에서 테스트 도구의 사용자 정보 조회가 실패하여 승인된 일반 실행 환경에서 검증했다. 애플리케이션 테스트 실패가 아니다.

## 데모 / 시작 화면 자동 회귀 검증

빈 상태에 시드 데이터를 넣지 않는지, 기존 데모 저장값이 유지되는지, 첫 프로젝트 저장·재방문이 데모와 섞이지 않는지, 재온보딩·다른 조직·오래된 탭의 덮어쓰기를 거부하는지, 손상된 저장값을 데모로 대체하지 않는지 확인했다. 4개 테스트를 추가했고 기존 16개도 통과했다.

## 브라우저에서 확인한 동작

- 프로젝트 생성: 이름·목적·예산으로 생성, 평가 지표 없이 요약 화면 진입.
- 업무 상태: ‘10월 방문 일정 나누기’를 완료로 변경, 캘린더에서 해당 일정 유지.
- 성과 확인: 검토 전 91명 제외 → 확인 후 91명, 목표 120명 대비 75.8% 표시.
- 보고서: 해당 확인 실적과 예산·근거를 포함한 스냅샷 생성·표시.
- 파일: 직접 만든 무개인정보 TXT 예시를 등록, 새로고침 후 자료 목록에 유지.
- 테마: 숲에서 흙으로 변경, 화면에 반영.
- 좁은 화면: 페이지 전체의 가로 넘침 없음(DOM 폭 344px 일치). 숫자 줄바꿈을 발견하여 요약 패널을 2열로 조정하고 통화 표시를 보완.
- 콘솔 오류·경고 조회 결과 없음.

## 검증 한계

- 브라우저 자동화의 다운로드 완료 이벤트가 시간 초과되어 최종 다운로드 파일 수신은 확인하지 못했다. HTML 생성 함수의 출력과 이스케이프는 자동 테스트로 확인했다.
- 파일 선택 자동화가 지연되었으나 최종 등록·재로딩 후 목록 유지는 확인했다. 버전 추가와 원본 재다운로드의 전체 UI 흐름은 추가 확인이 필요하다. 원본 버전 참조 보존은 자동 테스트로 검증했다.
- 모바일 최종 스크린샷 캡처가 도구 오류로 완료되지 않았다. 초기 모바일 화면을 시각 확인했고 수정 후 DOM 폭만 확인했다. 반응형 최종 시각 검수는 후속 과제다.
- 서버 권한, 실제 협업, HWPX 추출/편집, AI 처리, 정식 제출·승인은 이번 구현과 검증 대상이 아니다.

`screenshots/home-desktop.png`는 이번 로컬 기본 화면의 캡처다. 검증을 위해 추가한 예시 프로젝트/업로드/보고서는 검증 브라우저에만 남으며 초기 배포 데이터에는 포함되지 않는다.

## 2026-10-05 진입 경로 추가 검증

- 브라우저에서 조직명·담당자 입력 → 예시 없는 빈 홈(프로젝트 0개) → 첫 프로젝트 생성(프로젝트 1개)을 확인했다.

- 콘솔 오류·경고 없음. 좁은 화면에서 시작 화면을 시각 확인했고 DOM 폭 344px/scrollWidth 344px로 가로 넘침이 없었다. 전체 업무 화면의 모바일 검수는 이전 제한 사항을 따른다.
- `screenshots/start-preview.png`, `screenshots/empty-workspace.png`는 실제 로컬 화면이다. 검증 데이터는 로컬 테스트 주소에만 입력했다.

## 계정·조직·관리자 서버 단계

- 인증 없는 쓰기, 다른 조직 직접 조회, 외부 Origin, 초대 이메일 불일치/만료/취소/재사용, 프로젝트 미배정/회수, 구성원 중지, 읽기 전용 쓰기를 거부하는 API 검증을 SQLite 트랜잭션으로 수행했다.
- 같은 요청 UUID의 중복 반영 방지, 다른 내용의 UUID 재사용 거부, 이전 revision 덮어쓰기 거부를 확인했다.
- 원본 파일 메타데이터를 서버 값으로 정규화하고 조직 접근/다운로드 권한을 검증했다. R2 객체 저장은 테스트 어댑터로 검증했으며 실제 운영 파일 업로드는 별도 인수 대상이다.
- 전체 관리자 기본 거부, 명시 지정 계정만 허용, 내부 본문을 제외한 조직 메타데이터, 사유 필수의 정지와 감사 기록을 검증했다.
- 브라우저에서 공식 loopback 개발 인증 → 빈 조직 → 첫 프로젝트 서버 저장 → 조직 관리자 → 초대 링크 생성까지 확인했다. 운영 환경 인증은 배포 후 별도 확인한다.
- 로컬 검증 계정/조직은 운영 DB에 옮기지 않는다. 조직 관리자 화면 캡처는 `screenshots/organization-admin-local.png`다.
